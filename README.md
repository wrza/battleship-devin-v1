# Battleship

A browser-based single-player Battleship game built with React 18.

Play online: https://wrza.github.io/battleship-devin-v1/

## How to play

Place your five ships on the **Your Fleet** grid, rotating with the button or the `R` key. You can place ships manually or use **Random placement**, then start the game. Fire at cells in **Enemy Waters**; red cells are hits and blue cells are misses. The computer fires back after each shot. Sink every enemy ship before it sinks yours.
